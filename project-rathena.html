Software Development / Project 02

rAthena Server Customization

오픈소스의 구조를 읽고, 웹·데이터베이스·서버를 연결하며 쌓은 개발 및 유지보수 경험.

프로젝트 소개웹 · 데이터베이스서버 기능문제 분석개발 과정

01 / PROJECT OVERVIEW

기존 시스템을 이해하고,
필요한 기능을 더하는 작업.

rAthena 오픈소스 게임 서버를 기반으로 기존 시스템을 분석하고 필요한 기능을 추가하거나 수정한 개인 개발 프로젝트입니다.

GPT를 개발에 활용하기 전부터 rAthena를 다뤄 왔습니다. 이후 기존 경험을 바탕으로 AI 도구를 코드 분석과 수정의 보조 수단으로 활용했습니다.

서버 실행 환경 구성, MariaDB 데이터 관리, PHP 기반 웹페이지 수정, 게임 콘텐츠 스크립트 작성을 통해 기능 구현과 문제 해결 경험을 쌓았습니다. 서버 엔진 자체를 새로 개발한 것이 아니라, 기존 오픈소스를 활용하고 수정한 작업입니다.

02 / DEVELOPMENT ENVIRONMENT

사용한 환경과 도구

기능을 처음부터 모두 작성하기보다 기존 코드의 흐름과 실행 환경을 확인하며 수정하는 데 활용했습니다.

서버 환경
Windows에서 rAthena 실행 환경 구성, AutoSet 기반 Apache·PHP·MariaDB 활용
웹 · 데이터
PHP 회원가입 페이지의 기존 코드 수정, MariaDB 연결 및 계정·게임 데이터 관리
서버 코드
Visual Studio를 활용한 C++ 기존 소스 분석 및 수정, rAthena Script 콘텐츠 작업
개발 도구
Cursor·Codex로 코드 분석과 수정 보조, Git으로 변경 이력 관리

위 기술은 이 프로젝트에서 활용한 범위이며, PHP·C++ 전문 개발 경력을 의미하지 않습니다.

03 / WEB & DATABASE INTEGRATION

웹페이지부터 데이터베이스 연결까지

PHP 회원가입 페이지 수정

서버 회원가입 페이지를 구성하고 기존 HTML·PHP 코드를 읽으며 필요한 부분을 수정했습니다. 화면과 서버 측 처리 코드가 어떻게 연결되는지 확인하는 경험을 쌓았습니다.

MariaDB 환경 구성과 데이터 관리

서버 데이터베이스를 구성하고 연결 상태를 확인했습니다. 계정·게임 데이터를 관리하면서 데이터베이스 환경과 연결 문제를 점검했습니다.

AutoSet 기반 웹서버 활용

Apache·PHP·MariaDB 실행 환경을 활용하고 기존 시스템의 환경 및 버전 호환성을 검토했습니다. 별도의 데이터베이스 설계나 PHP 버전 업그레이드 완료 사례로 제시하지 않습니다.

04 / GAME SERVER DEVELOPMENT

콘텐츠 조건과 기존 기능을 수정하는 경험

rAthena Script 기반 콘텐츠

NPC 스크립트와 이벤트 콘텐츠를 작성·수정하고, 인스턴스 던전 및 보스 콘텐츠의 보상·쿨타임 조건을 다루었습니다. 콘텐츠를 서버에 적용하고 동작을 확인하며 조건 처리와 이벤트 흐름을 점검했습니다.

C++ 기존 소스 분석 및 수정

기존 서버 소스의 구조와 기능을 확인하고 필요한 부분을 수정했습니다. 버전 차이에 따른 호환성을 살펴보며 기능 포팅을 시도했습니다. 포팅 시도 자체를 완료된 기능으로 소개하지 않습니다.

05 / TROUBLESHOOTING

증상에서 원인 후보를 좁혀가기

문제 발생 당시의 조사 경험입니다. 수정 완료나 원인 확정이 확인되지 않은 부분은 구분해 기록했습니다.

SCRIPT EVENTS

몬스터 처치 이벤트의 처리 충돌

스크립트 · 이벤트 흐름 분석

증상
여러 스크립트가 몬스터 처치 이벤트를 사용할 때 의도대로 처리되지 않는 문제가 발생했습니다.
조사
관련 스크립트와 이벤트 처리 구조를 확인하며 충돌 원인을 조사하고 개선 방안을 검토했습니다.
범위
이벤트 처리 흐름을 분석한 경험으로 소개합니다. 구체적인 수정 완료와 재검증 결과는 확인되지 않아 해결 완료로 단정하지 않습니다.

06 / DEVELOPMENT PROCESS

기존 rAthena 경험에 AI 도구를 더하며

rAthena 작업은 GPT 활용 이전부터 이어져 왔습니다. 이후에는 Cursor와 Codex를 코드 분석·수정의 보조 도구로 활용하며, 제안된 코드를 실제 환경에 적용하고 오류를 확인하는 과정을 반복했습니다. 아래는 AI 도구를 도입한 이후의 작업 흐름입니다.

  1. 요구사항 정리필요한 기능과 동작 조건 정리
  2. 기존 구조 분석관련 코드와 이벤트 흐름 확인
  3. AI 보조 수정Cursor·Codex와 수정안 검토 및 적용
  4. 테스트와 반복테스트 서버 적용 → 오류 확인 → 수정 → 동작 검증

07 / RESULT & EXPERIENCE

개발과 운영 환경을 함께 바라보게 되었습니다.

기존 오픈소스 구조를 읽고 필요한 부분을 수정하면서, 기능 코드뿐 아니라 웹서버·데이터베이스·실행 환경까지 함께 확인하는 경험을 쌓았습니다.

PHP 웹페이지 수정, MariaDB 활용, 콘텐츠 스크립트 작성과 반복 테스트를 통해 기존 소프트웨어를 이해하고 유지보수하는 과정을 경험했습니다.

기업 실무 경력이 아닌 개인 개발 프로젝트입니다. 이 페이지는 작업 경험을 정리한 소개이며, 현재 운영 중인 서비스나 실시간 시연을 제공하지 않습니다.
